# Security Policy

## Supported version

Security fixes are currently applied to the latest public release of QFact.WE2Video.

## Reporting a vulnerability

Please do not publish a working exploit or sensitive security issue in a public GitHub Issue. Contact the maintainer through the GitHub profile linked to this repository and provide enough detail to reproduce the problem safely.

QFact.WE2Video launches Wallpaper Engine and FFmpeg locally, reads installed wallpaper metadata and writes exports to a user-selected folder. It does not require account credentials and does not collect payment-card information.
