# Как сохранить обои Wallpaper Engine в видео

**QFact.WE2Video** — бесплатная Windows-утилита для экспорта установленных обоев Wallpaper Engine в обычные видеофайлы: **MP4, WebM, MKV, MOV или GIF**.

Поддерживаются **Scene, Web и Video** обои.

## Быстрый способ

1. Запустите QFact.WE2Video.
2. Выберите нужные обои в библиотеке.
3. Для универсального результата выберите **MP4 · H.264**.
4. Укажите разрешение, FPS и длительность.
5. При необходимости включите звук.
6. Для Scene/Web при желании откройте **Clean Export** и вручную отключите лишние модули, которые автор обоев вынес в настройки.
7. Нажмите **Экспортировать**.
8. После завершения программа покажет уведомление и сохранит готовый файл в выбранную папку.

## Как программа обрабатывает разные типы обоев

### Scene
QFact.WE2Video запускает сцену в отдельном окне Wallpaper Engine, захватывает только это окно через Windows Graphics Capture и кодирует результат через FFmpeg.

### Web
Web-обои также запускаются через Wallpaper Engine и записываются из отдельного окна рендера.

### Video
Если обои уже являются видео, программа не записывает экран. Исходный видеофайл передаётся напрямую в FFmpeg, поэтому качество не зависит от захвата окна и не появляется чёрный экран из-за pop-out режима.

## Как убрать часы, дату, визуализатор и другие элементы

В **Manual Clean Export** программа показывает доступные корневые переключатели, которые автор обоев сделал настраиваемыми. Вы сами выбираете, что отключить. Если переключатель является модулем и у него есть зависимые подпункты, интерфейс не засоряется этими подпунктами — модуль показывается одной строкой.

Важно: если элемент жёстко встроен автором в сцену и не вынесен в User Properties Wallpaper Engine, универсально отключить его без изменения проекта нельзя.

## Если программа не нашла Steam или Wallpaper Engine

Нажмите **Steam / WE** в верхней панели и вручную выберите корневую папку Steam, SteamLibrary, `steamapps` или папку установки Wallpaper Engine. Путь сохранится для следующих запусков.

## Что лучше выбрать

Для большинства случаев:

- формат: **MP4 · H.264**;
- разрешение: **1920×1080**;
- FPS: **60** для плавности или **30** для меньшего размера файла;
- звук: включать только если он реально нужен.
