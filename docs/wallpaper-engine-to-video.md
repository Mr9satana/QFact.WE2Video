# Wallpaper Engine to Video / MP4 / GIF Converter

**QFact.WE2Video** is a Windows tool for converting installed Wallpaper Engine wallpapers into normal video files. It supports **Scene, Web and Video wallpapers** and can export to **MP4, WebM, MKV, MOV and GIF**.

## Wallpaper Engine to video

If you need to save a Wallpaper Engine wallpaper as a normal video, QFact.WE2Video chooses the export pipeline based on the wallpaper type:

- **Scene** — rendered through Wallpaper Engine, captured with Windows Graphics Capture, then encoded by FFmpeg.
- **Web** — rendered through Wallpaper Engine and captured from a dedicated render window.
- **Video** — converted directly from the original media file instead of being screen-recorded.

Audio can be enabled or disabled. Scene/Web capture can run in the background, and Manual Clean Export can disable selected root modules exposed by the wallpaper.

## Конвертер Wallpaper Engine в видео

Если нужно сохранить обои из Wallpaper Engine как обычное видео, QFact.WE2Video позволяет экспортировать их в MP4, WebM, MKV, MOV или GIF. Scene и Web обои рендерятся через Wallpaper Engine, а Video-обои конвертируются напрямую из исходного файла.
