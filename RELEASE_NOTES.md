# QFact.WE2Video v1.0.3

First public stable release of QFact.WE2Video.

## Highlights

- Export Wallpaper Engine Scene, Web and Video wallpapers to MP4, WebM, MKV, MOV or GIF.
- Direct FFmpeg conversion for Video wallpapers.
- Windows Graphics Capture pipeline for Scene/Web wallpapers.
- Optional audio capture.
- Background Capture mode.
- Manual Clean Export with root module switches.
- Automatic Steam / Wallpaper Engine discovery plus manual folder selection.
- Full Russian and English interface.
- Built-in help and developer-support link.
- Self-contained single-file Windows x64 release.

## Requirements

Windows 10 2004+ or Windows 11. Wallpaper Engine is required for Scene/Web wallpapers. FFmpeg/ffprobe and Microsoft Edge WebView2 Runtime are required at runtime.

QFact.WE2Video is independent software and is not affiliated with Wallpaper Engine, Valve or Steam.
